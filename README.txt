SISTEMA DE GESTION DE CONSENTIMIENTOS DE PROCEDIMIENTOS MEDICOS 
SGCPM-ISIM (INSTITUTO DE LA MUJER RIOBAMBA)

EL SISTEMA TIENE COMO OBJETIVO, SALVAR, RECOPILAR Y ALMACENAR DE MANERA SEGURA EL REGISTRO SOBRE EL CONSENTIMIENTO OBTENIDO PREVIO A LOS PROCEDIMIENTOS MEDICOS A REALIZAR EN EL INSTITUTO DE LA MUJER RIOBAMBA
ESTE SISTEMA TAMBIEN CUENTA CON UN MODULO DE PACIENTES DE DONDE PUEDO HACER UN CRUD Y UN MODULO DE DOCUMENTOS, DONDE SE PUEDE VER EL DOCUMEMNTO CREADO , SE LO PUEDE FIRMAR ,Y SI EXISTEN CAMBIOS ENTONCES SUS DIFERENTES VRSIONES SE SEGUIRAN ALMACENANDO.


FLUJO NORMAL, INGRESO AL SISTEMA Y ME PIDE SELECCIONAR UN USUARIO, LUEGO UN DOCUMENTO, LUEGO ME DICE FIRMAR O LEER, DOY EN FIRMAR, 
EL PACIENTE FIRMA EN UNA PANTALLA SECUNDARIA QUE SE ABRE EN EL MONITOR EXTERNO, ESTE MONITOR  ABRE LA PAGINA DE FIRMA USANDO WEB SOCKETS, Y CAPTURA LA FIRMAM EN UNA BASE DE DATOS Y LA PONE AL FINAL DEL DOCUMENTO. NADA MAS
